# SAFAR TJ — учебный веб-проект

**Тема:** Разработка веб-проекта туристического агентства для туров по Таджикистану.  
**Лабораторная работа №9:** Дизайн интерфейса в Figma.

## Что есть в проекте

- `index.html` — главная страница.
- `tours.html` — список туров с поиском.
- `tour.html` — информация о выбранном туре.
- `booking.html` — форма заявки.
- `style.css` — оформление страниц.
- `script.js` — простой поиск и проверка формы.
- `imags/` — рисунки для сайта (название папки с небольшой опечаткой).
- `docs/09-design/` — схемы, вайрфреймы, UI-kit и картинки экранов.

## Как запустить

1. Распаковать ZIP.
2. Открыть папку в Visual Studio Code.
3. Нажать правой кнопкой на `index.html` и выбрать **Open with Live Server**.
4. Проверить главную страницу, каталог, карточку тура и форму заявки.

## Что работает

Поиск по названию, фильтр по региону, переходы между страницами, выбор тура и проверка заполнения обязательных полей. После отправки формы появляется сообщение. Сведения **не отправляются на сервер**. Указанные цены используются как пример, а не как реальные предложения.

## Работа в Figma

Файлы для подготовки дизайна лежат в `docs/09-design/`. Для завершения лабораторной нужно самостоятельно создать файл Figma, перенести макеты на 4 страницы: `01 Flow`, `02 Wireframes`, `03 UI-kit`, `04 Mockups`; сделать компоненты и переходы Prototype и добавить ссылки в `ui-kit.md`.

## Что можно доделать потом

Настоящую базу данных, личный кабинет и отправку заявок. Сейчас это простая учебная версия.
